Design rules this layout encodes

  • No learned component sits on the path between the safety controller and the drives.
  • Every learned output passes through a classical filter that enforces limits before reaching a controller (stage 09).
  • Slow components (reasoner, policy) are asynchronous to fast ones; their deadline misses degrade capability, not stability.
  • On humanoids the fastest learned component (whole-body tracker) gets a dedicated priority so a slow VLA chunk can never starve balance control.
  • Every process emits telemetry with the version tuple; the logger keeps a ring buffer for incident bundles.
