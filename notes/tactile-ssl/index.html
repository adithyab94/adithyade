One encoder, many ways to feel

Robot touch comes in incompatible shapes: 1D pressure arrays, 3-axis force taxels, and camera-based sensors that see their own gel. These notes walk through one way to learn a shared representation from all of them without labels: per-sensor stems into a shared transformer, trained with the DINOv2 recipe (DINO, iBOT, KoLeo) and an EMA teacher. Debug order

  1. Check the batch contract: one sensor type per batch, the same on every rank.
  2. Check normalization: per-sensor statistics, computed on training data only.
  3. Check the token count: frames × taxels after chunking, plus registers.
  4. Watch for collapse: teacher entropy, KoLeo term, probe accuracy, before the total loss.
  5. Only then tune: mask ratio, crop sizes, temperatures, loss weights, momentum.
